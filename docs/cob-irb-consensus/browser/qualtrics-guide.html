Qualtrics is PI-owned and project-specific. This pack does not host surveys or pull response data. Mock templates are Public synthetic copy for PIs to rebuild in Qualtrics.

Qualtrics integration (guidance)

PI pattern

  1. Describe Qualtrics (or equivalent) as the data-collection instrument in the HSIRB protocol.
  2. Build and host the live survey in the PI’s university Qualtrics account.
  3. Keep responses in Qualtrics. Do not commit response CSVs to GitHub.
  4. If CoB IRB needs to see the instrument, share screenshots or a View link via Drive / approved channels — not by pasting responses into consumer AI.
  5. Recruitment and session scheduling remain project-specific (not an in-house SONA replacement).
  6. Course credit stays with instructors; document an equivalent alternate assignment in the protocol when credit is offered.

What we do not build

  • Qualtrics API sync into GitHub or this browser pack
  • Drive bots that auto-ingest response CSVs
  • In-house anonymous signup SaaS that would trigger IT product concerns

Protocol language (example)

“Participants will complete study measures via Qualtrics (or equivalent university-approved survey software). Survey links are managed by the PI. Response data are stored in the PI’s Qualtrics project under university account controls. No participant response files are stored in public code repositories.”
